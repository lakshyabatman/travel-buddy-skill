Flight Points Optimiser

The cheapest way to fly, cash or points, without booking anything for you.

  • Cash and points together. One ranking, from free sources, for any city pair.
  • The real total. Bags and seats are added when they can be verified. Unknown fees stay unknown.
  • You stay in control. Visa flags and award links are cited. The skill never pays or transfers points unless you say so.
git clone https://github.com/lakshyabatman/travel-buddy-skill.git && cd travel-buddy-skill && chmod +x scripts/install.sh && ./scripts/install.sh --claude-code

One command for Claude Code. Use --cursor instead for Cursor. The skill also works by opening SKILL.md with no install.

What it does

  • Searches cash fares first with the agent’s built-in flight search, then Google Flights, Skyscanner, Kayak, the airline’s own site, or the bundled search.py.
  • Asks whether the dates are flexible, and by how much, before it searches. Exact dates are used only when you say the dates are fixed. If it cannot ask, it searches ±3 days and says so.
  • Tries that date window, nearby and secondary airports in whatever region you are flying from, positioning hops, open-jaw itineraries, rail plus air, and separate tickets via hubs.
  • Asks about bags, seats, and changes, then ranks by the true total: the base fare plus the fees you would really pay. A headline fare that leaves those out is flagged. Unknown fees stay unknown.
  • Asks each traveller’s passport and any visa they already hold — there is no default nationality — and checks transit and entry from official sources.
  • Compares award tickets using cards/<country>.yaml when that issuing country has a file. v1 includes one country file, India. If your country or card isn’t in a file yet, the agent researches the issuer’s official page and labels figures unverified.
  • Leads with up to three picks, then one table of cash, points, other dates, and other airports, then the booking steps for the picks only. It can also set a price-watch that alerts only when the fare actually drops.

Source of truth: SKILL.md. Every fare, fee, ratio, and visa rule must cite a source. Transfers are almost always irreversible. Nothing here assumes a home country.

Install

Clone the repo, then use the install script or paste a prompt. The repository is lakshyabatman/travel-buddy-skill; the skill is flight-points-optimiser. This page is published at lakshyabatman.github.io/travel-buddy-skill.

git clone https://github.com/lakshyabatman/travel-buddy-skill
cd travel-buddy-skill
chmod +x scripts/install.sh

Claude Code

./scripts/install.sh --claude-code

Copies the skill to ~/.claude/skills/flight-points-optimiser/. In a project: ./scripts/install.sh --project.

Cursor

./scripts/install.sh --cursor

Copies the skill to ~/.cursor/skills/flight-points-optimiser/. This repo also ships a Cursor rule at .cursor/rules/flight-points-optimiser.mdc that points at SKILL.md.

Codex and other AGENTS.md readers

When you work inside this repository, AGENTS.md already points at SKILL.md. To use it in another repo (copies the skill in and adds a relative pointer to AGENTS.md):

./scripts/install.sh --agents --project-dir /path/to/other-repo

Any LLM

Open prompts/any-llm.md, paste it into the chat, and attach a card file if you have one. No skills folder required.

Disclaimer

Transfer ratios, partners, caps and fees change often, sometimes overnight. Entries marked unverified come from blogs, or from official pages that are old or behind a login. Confirm the ratio in your bank’s transfer portal, and confirm award space on the airline programme’s site, before transferring. This project is not affiliated with any bank, airline or loyalty programme, and nothing here is financial advice.
